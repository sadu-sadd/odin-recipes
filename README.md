# Odin Recipes

A small multi-page recipe site built with plain HTML as part of The Odin Project.

**Live site:** https://sadu-sadd.github.io/odin-recipes/

## Recipes
- Masala Dosa
- Vegetable Biryani
- Idli Sambar

## What I practised
- Relative paths between folders
- Semantic HTML (header, nav, main, article, footer)
- Ordered and unordered lists
- Images with proper `alt`, `width`/`height`, and figcaption
- Meta descriptions for SEO
